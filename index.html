Interactive Probability Tree Diagram Builder

Define tree layers and branches, assign event names and conditional probabilities, and analyze outcome paths using the Multiplicative Rule of Probability.

How to Use This Tool

  • 1. Set Up Tree Structure: Choose the number of layers (depth) and how many branches originate from each node, or select a preset example.
  • 2. Label Events & Probabilities: Edit event names and conditional probabilities for every node. Probabilities for branches leaving any single node must sum to 1.0. Use "Auto-Balance = 1.0" if needed.
  • 3. Explore Outcome Paths: Review the generated tree diagram and table of all end-to-end paths. Hover over or focus (`Tab`) on any row in the table to highlight that path in the diagram.
